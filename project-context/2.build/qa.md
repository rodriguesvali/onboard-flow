## 5. Defects

Blocking defect found during Agentic Architect review and remediated:

- `Solicitar ajustes` called backend refinement, but the frontend state machine ignored the returned `RUN_DONE` event while already in `done` state. The backend returned the refined plan, but the visible result stayed unchanged. Fixed by allowing `RUN_DONE` to replace the current result from `done` state and by making the success banner explicit: `Ajustes aplicados ao plano. Revise a nova versao antes de aprovar.`

Validation after fix:

- Frontend tests passed: 4 files, 15 tests.
- Angular production build passed.
- Prettier check passed.

Second blocking defect found during Agentic Architect retest and remediated:

- The screen accepted the refinement response, but the backend deterministic refinement only recorded the request as a pending action, so the generated plan content did not visibly change. The application service also needed to call the configured Flow refinement first and only use deterministic fallback after a Flow failure.
- Fixed by routing refinement through `flow.refine` first and making deterministic refinement update visible plan content: executive summary, next recommended actions, pending actions, and the section inferred from the instruction, such as initial agenda, documents, IT checklist, training path, or risks.

Validation after second fix:

- Backend tests passed: 3 files, 9 tests.
- Python compile check passed for `src` and `tests`.
- Deterministic API smoke confirmed `POST /api/onboarding/runs/{runId}/refine` returns `revisionNumber=2`, `status=draft`, an updated executive summary, a new `Revisao da agenda inicial solicitada` item in `initialAgenda`, and the original adjustment instruction in `pendingActions`.

Observed non-blocking issue:

- The local backend reads runtime mode from environment configuration. When the operator wants provider-free smoke validation, the command should set `ONBOARDFLOW_FLOW_MODE=deterministic` explicitly; otherwise a local `.env` configured for CrewAI can attempt live execution.
