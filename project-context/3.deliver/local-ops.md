## 1. Purpose

This runbook documents how to run and validate the approved OnboardFlow AI MVP locally for deterministic demos.

The default local demo must not call live Gemini, CrewAI AMP, email, service desk, HRIS, IAM, LMS, chat, or provisioning services.

## 2. Local Demo Profile

Use this profile for normal demos, QA checks, and CI-like local validation:

```text
ONBOARDFLOW_FLOW_MODE=deterministic
CREWAI_AMP_TRACING=false
DATABASE_URL=sqlite:///./onboardflow.db
```

Expected behavior:

- Backend uses deterministic Flow behavior.
- No real LLM/provider call is executed.
- No trace is published to CrewAI AMP.
- Simulated dispatch returns receipts but does not call email or service desk systems.

## 3. Prerequisites

Required:

- Python `3.12`.
- `uv`.
- Node compatible with the Angular 21 frontend. The Dev Container currently provides Node 24.
- npm `11.13.0` or compatible with `frontend/package-lock.json`.

Lock files:

## 4. Backend Setup

From repository root:

```text
cd backend
uv sync --all-extras --dev
uv run alembic upgrade head
```

Run backend in deterministic demo mode:

```text
ONBOARDFLOW_FLOW_MODE=deterministic CREWAI_AMP_TRACING=false \
  uv run uvicorn onboardflow.api.main:app --app-dir src --host 127.0.0.1 --port 8000
```

Expected startup log includes:

```text
onboardflow_backend_started flow_mode=deterministic crewai_amp_tracing=False
```

## 5. Frontend Setup

From repository root in a second terminal:

```text
cd frontend
npm ci
npm start -- --host 127.0.0.1 --port 4200
```

Open:

```text
http://127.0.0.1:4200/onboarding/generate
```

The frontend currently reads the backend URL from `frontend/src/environments/environment.ts`:

```text
http://localhost:8000
```

For local demo, keep the backend on port `8000`.

### Full API Smoke: Generate And Dispatch

Run from repository root while the backend is running:

```text
python - <<'PY'
import json
import urllib.request

base_url = "http://127.0.0.1:8000"
payload = {
    "fullName": "Ana Silva",
    "email": "ana.silva@example.com",
    "role": "Engenheira de Software",
    "department": "Engenharia",
    "directManager": "Joaquim",
    "startDate": "2026-06-15",
    "employmentType": "Tempo integral",
    "workMode": "Remoto",
    "seniority": "Pleno",
    "contractRegion": "BR",
    "preferredLanguage": "pt-BR",
    "equipmentNeeds": "Notebook",
    "specialAccessNotes": "",
}

def post(path, data=None):
    body = json.dumps(data or {}).encode("utf-8")
    request = urllib.request.Request(
        f"{base_url}{path}",
        data=body,
        headers={"Content-Type": "application/json"},
        method="POST",
    )
    with urllib.request.urlopen(request) as response:
        return json.loads(response.read().decode("utf-8"))

def get(path):
    with urllib.request.urlopen(f"{base_url}{path}") as response:
        return json.loads(response.read().decode("utf-8"))

run = post("/api/onboarding/generate", payload)
run_id = run["runId"]
status = get(f"/api/onboarding/runs/{run_id}")
dispatch = post(f"/api/onboarding/runs/{run_id}/dispatch")
status_after_dispatch = get(f"/api/onboarding/runs/{run_id}")

print(
    json.dumps(
        {
            "runId": run_id,
            "status": status["status"],
            "employee": status["result"]["employeeProfile"]["fullName"],
            "dispatchTotal": dispatch["dispatchSummary"]["total"],
            "email": dispatch["dispatchSummary"]["email"],
            "serviceDesk": dispatch["dispatchSummary"]["serviceDesk"],
            "persistedReceipts": len(status_after_dispatch["dispatchReceipts"]),
            "aiToolAccessSentToServiceDesk": any(
                receipt["taskTitle"] == "Ferramentas de IA aprovadas"
                and receipt["channel"] == "service_desk"
                for receipt in dispatch["receipts"]
            ),
            "aiTrainingSentByEmail": any(
                receipt["taskTitle"] == "Uso responsavel de IA"
                and receipt["channel"] == "email"
                for receipt in dispatch["receipts"]
            ),
        },
        ensure_ascii=False,
        indent=2,
    )
)
PY
```

Expected:

- `status` is `done`.
- `dispatchTotal` is greater than `0`.
- `persistedReceipts` equals `dispatchTotal`.
- `aiToolAccessSentToServiceDesk` is `true`.
- `aiTrainingSentByEmail` is `true`.

## 9. Live Provider Procedure

Use only when live provider spend and trace publication are intentionally approved.

```text
cd backend
uv sync --all-extras --dev
uv run crewai login
uv run crewai traces enable
uv run crewai traces status
export ONBOARDFLOW_FLOW_MODE=crewai
export CREWAI_AMP_TRACING=true
export GEMINI_API_KEY=<secret>
uv run uvicorn onboardflow.api.main:app --app-dir src --host 127.0.0.1 --port 8000
```

Then generate or refine a plan from the frontend. Startup alone does not publish traces; CrewAI must reach `Crew.kickoff()`.

## 10. Troubleshooting

Backend cannot import `onboardflow`:

- Run commands from `backend/`.
- Use `uv run ...`; backend tests configure `pythonpath = ["src"]`.
- For ad hoc scripts from `backend/`, use `PYTHONPATH=src` when needed.

Frontend cannot reach backend:

- Confirm backend is on port `8000`.
- Confirm `API_CORS_ORIGINS` includes both `http://localhost:4200` and `http://127.0.0.1:4200`.
- Confirm `frontend/src/environments/environment.ts` points to `http://localhost:8000`.

Database errors:

- Run `uv run alembic upgrade head`.
- Delete local demo SQLite only when no local run history needs to be preserved.

Unexpected live provider calls:

- Confirm `ONBOARDFLOW_FLOW_MODE=deterministic`.
- Confirm no local `.env` overrides flow mode to `crewai`.

CrewAI AMP traces do not appear:

- Confirm live mode is enabled.
- Confirm `CREWAI_AMP_TRACING=true`.
- Confirm `uv run crewai login`, `uv run crewai traces enable`, and `uv run crewai traces status`.
- Execute generate or refine; startup alone does not publish traces.
