Phase: Define

Status: Pending Agentic Architect review

## 1. Purpose

This document defines mandatory development tools for OnboardFlow AI. These tools are architectural and delivery constraints for the Build phase.

Coding must not begin unless the required tools below are available to the development agents.

## 2. Mandatory Tools

### 2.1 MCP Server Context7

Requirement: mandatory before coding, except where superseded by the PrimeNG MCP Server requirement for PrimeNG frontend development.

Purpose:

- Obtain up-to-date technical documentation before any coding activity.
- Reduce implementation drift caused by stale framework, library, or API knowledge.
- Support architecture and implementation decisions with current source material.

Usage rule:

- Before coding, development agents must use MCP Server Context7 to retrieve current documentation for the relevant technologies, libraries, frameworks, or APIs.
- The documentation check must happen before implementation work begins.
- The retrieved context should inform implementation choices, code structure, and usage patterns.

### 2.2 PrimeNG MCP Server

Requirement: mandatory for frontend development because the frontend will use PrimeNG.

Purpose:

- Support frontend implementation with current PrimeNG documentation and component guidance.
- Ensure UI development follows PrimeNG-supported patterns and APIs.
- Reduce risk of incorrect component usage, outdated examples, or unsupported styling approaches.

Usage rule:

- For frontend tasks involving PrimeNG, development agents must use the PrimeNG MCP Server before coding.
- In PrimeNG-specific frontend work, the PrimeNG MCP Server is the primary required documentation source.
- For PrimeNG-specific frontend work, MCP Server Context7 becomes optional and complementary.

## 3. Availability and Blocking Rule

If MCP Server Context7 or the PrimeNG MCP Server is required for a coding task and is not available, coding is blocked.

The development agent must not proceed with implementation until the availability issue is resolved by the Agentic Architect.

Blocked conditions include:

- Required MCP server is not configured.
- Required MCP server cannot be reached.
- Required MCP server fails to return usable documentation.
- Required MCP server is unavailable in the active development environment.

## 4. Agentic Architect Responsibility

It is the responsibility of the Agentic Architect to make the required tools available to the development agents.

The Agentic Architect must ensure:

- MCP Server Context7 is available before general coding begins.
- PrimeNG MCP Server is available before PrimeNG frontend coding begins.
- Any tool availability issue is resolved before implementation resumes.

## 5. Build Phase Enforcement

During Build phase:

- Development agents must verify tool availability before starting coding.
- Development agents must document when required tooling is unavailable.
- Development agents must treat missing required tooling as a blocker, not as an optional warning.
- Development agents must not substitute stale local knowledge for required MCP documentation when a mandatory MCP server is unavailable.

## 6. Scope

This document applies to:

- Frontend implementation.
- Backend implementation.
- Integration work.
- QA automation when framework or library documentation is needed.
- Any coding task that depends on current external framework, library, or API behavior.
